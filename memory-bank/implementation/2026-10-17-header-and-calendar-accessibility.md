# A22 — Header and calendar accessibility

The header notification and account menus use a Headless UI `Popover.Group`; first focus, Escape returning to the trigger, closing each other and focus moving to an outside target are tested. The manual document listeners and the second popover path were removed. Search is a single form submission. Notification pending, error, retry and genuinely empty states are separate; on a failed background read, stale data is marked clearly, an unknown unread count is not shown and the mark-as-read write is disabled. The list is the last 5 completed sessions; local read state is per account. After an action, focus returns to the persistent close button and the result is announced. A late account read is rejected at the epoch boundary.

In the calendar, the existing empty-hour buttons moved to a single Tab stop with arrow, Home, End and Ctrl+Home/End navigation; Enter and Space open the existing editor. Labelled time and duration fields in the session actions offer an alternative to drag and resize and use the existing versioned write engine. Only changed fields are sent; on a 409 or read error the draft is kept, nothing is written without re-reading the source and no write is retried automatically. When the cell changes, focus returns to the new-session button, or to the Today button when outside the visible range. Small card commands became at least 24 px; not all overlaps of short neighbouring cards were solved.

`npm run check`: **18 contracts + 142 backend + 192 frontend = 352 tests**, nothing skipped; naming, strict, lint and production build passed. After the last focus fix, frontend strict mode, root lint, 192 tests and the build were verified again. There are 7 new header regressions and 10 calendar regressions across the daily and weekly views. A separate production fixture verified mark-as-read with 5 measured minutes, popover, Escape and focus, daily arrows, Home, End and Enter, and saving time and duration. A cell-change ref conflict found in the browser was fixed; focus returned to the new-session command. SQLite kept the two sessions, the note and the 300-second measurement; integrity and foreign keys were clean. The test session was signed out and the fixture processes, tab, database and helper files removed. No test writes, migration, seed, reset or restore on the real database; schema 006 was kept.

**A22 open:** automated real-browser tests, full WCAG and screen readers, Lighthouse, evidence on a real touch device, the DST fold and the short neighbouring card layout. This package does not close all of A22. The A04 and dependency backlog continued.
